# 🧠 BRAINY GAME

### An Interactive Quiz-Based Web Game

BRAINY GAME is an interactive browser-based quiz game designed to make general knowledge learning more engaging through gamification, animations, rewards, and an animated AI-inspired companion named **SPARKI**.

## ✨ Key Features

- 🎯 Interactive quiz gameplay
- 🤖 SPARKI — animated AI-inspired game companion
- 🧠 Randomized questions
- 📚 History, Politics & General GK categories
- ⏱️ Countdown timer for each question
- ❤️ Lives system
- 🔥 Streak system
- 🪙 Coins and rewards
- 🎮 Level progression
- 🌓 50/50 lifeline
- 📊 Progress tracking
- 🔊 Voice feedback using Web Speech API
- 🎉 Animated correct/wrong answer feedback
- 🏆 Performance-based result levels
- 💾 Local Storage for saving game data
- 📱 Responsive user interface

## 🛠️ Technologies Used

- **HTML5** — Structure and content
- **CSS3** — Styling, animations and responsive design
- **JavaScript** — Game logic and interactivity
- **Web Speech API** — Voice feedback
- **Local Storage API** — Persistent browser data

## 🎮 How to Play

1. Open the BRAINY GAME website.
2. Click **Start Challenge**.
3. Read the question and select your answer.
4. Answer before the timer runs out.
5. Build your **streak** by answering correctly.
6. Earn **coins** and increase your level.
7. Use the **50/50 lifeline** when needed.
8. Try to complete the challenge with the highest score possible.

## 🤖 Meet SPARKI

SPARKI is the animated AI-inspired companion of BRAINY GAME.

SPARKI provides:

- 💬 Interactive game comments
- 🔊 Voice feedback
- 🎉 Celebration animations
- 😮 Wrong-answer reactions
- ⚡ Motivational feedback
